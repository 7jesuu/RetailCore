# Карта стейкхолдеров RetailCore (для уточнения требований)

## 1. Ключевые роли для интервью (обязательные по заданию)

### Спонсор проекта со стороны бизнеса
(директор по цифровым продажам / аналог Дмитрия)

- Цель взаимодействия: цели изменений, приоритеты бизнеса, ожидаемый эффект, допустимые ограничения, критерии успеха.
- Основные темы: стратегия, метрики, ограничения «нельзя останавливать бизнес», баланс стабилизации и скорости, новые сценарии.
- Приоритет: критический.

### Руководитель команды заказов и оформления

- Цель взаимодействия: реальное устройство ключевого процесса, исключения, ручные операции, операционные проблемы.
- Основные темы: order flow, промо, каналы, статусы, отклонения, точки боли.
- Приоритет: критический.

### Технический лидер / ведущий разработчик монолитного ядра

- Цель взаимодействия: фактическое устройство системы, технические ограничения, зависимости, узкие места, техдолг.
- Основные темы: архитектура монолита, БД, интеграции, производительность, сложные зависимости.
- Приоритет: критический.

## 2. Дополнительные стейкхолдеры (рекомендуемые)

### Руководитель клиентской поддержки
- Зачем общаться: клиентские боли, прозрачность, ручные компенсации, влияние на SLA.
- Ключевые вопросы: статусы, расхождения, пики, инструменты оператора.
- Приоритет: высокий (есть стенограмма).

### Команда логистики
- Зачем общаться: логика доставки, партнёры, дублирование с финансовым блоком, статусы доставки.
- Ключевые вопросы: сценарии по типам поставки, рассинхроны, ручные вмешательства.
- Приоритет: высокий.

### Команда платёжных интеграций
- Зачем общаться: платёжные сценарии, повторные оплаты, возвраты, рассинхроны с заказом.
- Ключевые вопросы: callback’и, таймауты, частичные оплаты/возвраты.
- Приоритет: высокий.

### Аналитика и отчётность
- Зачем общаться: согласованность данных, «разные цифры», потребности в управленческом слое.
- Ключевые вопросы: источники данных, расхождения, требования к latency/consistency.
- Приоритет: высокий.

### Инфраструктура и эксплуатация
- Зачем общаться: on-premise ограничения, ресурсы, мониторинг, масштабирование, Oracle.
- Ключевые вопросы: мощности, виртуализация, архивирование, RTO/RPO.
- Приоритет: высокий.

### Команда маркетинга / промо
- Зачем общаться: сложность запуска акций, персонализации, партнёрских предложений.
- Ключевые вопросы: lead time изменений, исключения.
- Приоритет: средний.

### Внешние партнёры (выборочно)
Маркетплейсы, 1–2 службы доставки, платёжный провайдер.
- Зачем общаться: реальные контракты, SLA, особенности интеграций.
- Ключевые вопросы: форматы, частота обновлений, отклонения.
- Приоритет: средний.

### Security / Compliance (если есть)
- Зачем общаться: требования к данным, аудиту, импортонезависимости.
- Ключевые вопросы: ограничения на технологии и хранение.
- Приоритет: средний.

## 3. Карта влияния и интереса (упрощённо)

### Высокое влияние + высокий интерес (управлять closely)
- Спонсор бизнеса
- Руководитель команды заказов
- Техлид монолита
- Руководители логистики и платежей

### Высокое влияние + средний интерес (держать в курсе)
- Инфраструктура/эксплуатация
- Аналитика

### Среднее влияние + высокий интерес (вовлекать)
- Поддержка
- Маркетинг

### Низкое/среднее влияние (мониторить)
- Внешние партнёры (через контракты и интеграции)

## 4. Рекомендуемый порядок интервью

1. Спонсор бизнеса (уже есть частичная стенограмма — дополнить/уточнить).
2. Руководитель команды заказов и оформления.
3. Техлид монолитного ядра.
4. Поддержка (есть стенограмма — использовать для валидации).
5. Логистика + Платежи (параллельно или последовательно).
6. Аналитика + Инфраструктура.
7. Точечные уточнения у партнёров при необходимости.
